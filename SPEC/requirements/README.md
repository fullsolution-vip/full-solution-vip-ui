# Requirements

This folder tracks feature requirements for the Full Solution web application.
Each feature has its own file with acceptance criteria that QA/testing tools can reference.

## Structure

| File | Description |
|------|-------------|
| `authentication.md` | Signup, login, logout, session management |
| `chatbot.md` | AI chatbot with RAG, knowledge base, chat history |
| `client-portal.md` | Customer portal — chat history, product queries |
| `admin-portal.md` | Admin panel — users, knowledge base, products |
| `lead-generation.md` | Lead capture, forms, analytics |
| `performance.md` | Caching, Core Web Vitals, observability |
| `deployment.md` | Vercel deployment, environment config |

## Status Legend

- [ ] Not started
- [~] In progress
- [x] Done
- [!] Blocked
